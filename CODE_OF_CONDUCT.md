# Code of Conduct

*Em português: [CODE_OF_CONDUCT.pt-BR.md](CODE_OF_CONDUCT.pt-BR.md).*

Saci follows the [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

## Our standard

Be kind, assume good faith, welcome beginners — many people here are using an
LLM API for the first time, in a second language. Questions that look obvious to
you may be someone's first step.

Harassment, discrimination and personal attacks are not tolerated, in issues,
pull requests, discussions or anywhere the project meets.

## Enforcement

Reports go to the maintainer through GitHub (private message or the *Report
content* option). They are handled confidentially. The maintainer may warn,
remove content, or block accounts, depending on severity.

## Scope

This applies to every space the project occupies — the repository, discussions,
and any public space where someone is representing Saci.
