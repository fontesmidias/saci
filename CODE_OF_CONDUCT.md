# Code of Conduct

Saci follows the [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be kind, assume good faith, welcome beginners — many people here are
using an LLM API for the first time, in a second language. Harassment,
discrimination and personal attacks are not tolerated, in issues, PRs,
discussions or anywhere the project meets.

Reports go to the maintainer through GitHub (private message or the
*Report content* option). They are handled confidentially.

*Em português:* seja gentil, presuma boa-fé, acolha quem está começando.
Assédio e ataques pessoais não são tolerados. Denúncias vão ao mantenedor
pelo GitHub e são tratadas em sigilo.
