# Código de Conduta

*English version: [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md).*

O Saci segue o [Contributor Covenant 2.1](https://www.contributor-covenant.org/pt-br/version/2/1/code_of_conduct/).

## Nosso padrão

Seja gentil, presuma boa-fé, acolha quem está começando — muita gente aqui está
usando uma API de LLM pela primeira vez, num segundo idioma. Perguntas que
parecem óbvias para você podem ser o primeiro passo de alguém.

Assédio, discriminação e ataques pessoais não são tolerados, nem em issues, nem
em pull requests, nem em discussões, nem em qualquer lugar onde o projeto se
encontre.

## Aplicação

Denúncias vão ao mantenedor pelo GitHub (mensagem privada ou a opção *Report
content*). São tratadas em sigilo. O mantenedor pode advertir, remover conteúdo
ou bloquear contas, conforme a gravidade.

## Abrangência

Vale para todos os espaços que o projeto ocupa — o repositório, as discussões e
qualquer espaço público onde alguém esteja representando o Saci.
